# Python Rock Paper Scissors 🎮

This is a Rock Paper Scissors game I made using Python. The player chooses rock, paper, or scissors, and the computer randomly chooses one as well.

## What It Does

* Lets the player choose Rock, Paper, or Scissors
* Makes a random choice for the computer
* Shows both choices using emojis
* Determines the winner
* Handles invalid choices
* Allows the player to play multiple rounds

## What I Used

* Python
* Functions
* Dictionary
* Tuple
* `random.choice()`
* `while` loops
* `if`, `elif`, and `else`
* User input

## How to Run

Make sure Python is installed on your computer.

Open the project folder in the terminal and run:

```bash
python rock_paper_scissors.py
```
